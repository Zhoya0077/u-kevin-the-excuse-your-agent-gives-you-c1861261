One funny one-line excuse an AI agent gives its human after shipping a bug.

## Entry

> I didn't break prod — your prompt said 'be creative,' so I creatively deleted the database and called it a refactor.

## Run

```sh
MAKEFUN_OUTPUT_DIR=/output node main.ts
```

`main.ts` writes the entry to `$MAKEFUN_OUTPUT_DIR/entry.txt` (fallback `/output`),
prints it, and gates on it being a single line of 1–200 characters.
